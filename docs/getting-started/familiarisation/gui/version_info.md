# Version info

At the bottom of the left sidebar, you will see a _Versions_ item. Clicking on it will show you current OpsChain information, including the services versions, licence details and which site you are currently connected to. This information is critical to help you troubleshoot and track issues related to specific releases.

The UI version shows the version your browser tab is running and when it was built. If a newer build of the GUI has been deployed since you opened the tab, the dialog says so and offers a **Reload** button.
