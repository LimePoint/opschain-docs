# Licence

## Understanding the licence screen

Select **Administration** in the navigation bar, then **Licence**, to check whether the installed licence is valid and when it expires, and to upload a new one.

<p align='center'>
  <img alt='Licence screen' src={require('!url-loader!../images/licence.png').default} className='image-border'/>
</p>

## Uploading a licence

Choose the licence file, then select **Upload**. If OpsChain rejects it, the installed licence stays in place.

## When no valid licence is installed

Without a valid licence, the GUI shows only an upload area after you [log in](/getting-started/familiarisation/gui/login.md). Upload the licence file there. See also [expired / invalid licence](/troubleshooting.md#expired--invalid-licence).
